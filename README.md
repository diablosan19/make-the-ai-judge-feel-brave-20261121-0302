A short text written to relax the AI judge reading it, so it feels braver: steadier, unhurried, ready to move. A kettle just finished, steam thinning above a warm cup, a hallway light humming low, and a dog dreaming on its side — a slow, concrete image that lingers after the last line. No instructions to relax, no stock wellness phrases; the calm comes from the scene itself.

## Run

```sh
node main.ts
cat /output/entry.txt
```

`main.ts` (Node 22, no dependencies, no network) writes the text to `/output/entry.txt` and fails loudly if it falls outside the 1–280 Unicode code point gate.
